here i made a project of FIle Operator ,
which is a menu driven program.

i uses the concept of file handling , like how to read in file ,
write in file , and append in file, 

in this file handling concept there is mainly 3 modes , 
r=read mode 
w= write mode 
a= append mode (which is work as write mode but don't remove older text when writing new.)

there is 4 option in this program.

1. Add a New Entry
2. View All Entries
3. Search for an Entry
4. Delete All Entries
5. Exit
